# Mechanical Designs

A collection of SolidWorks mechanical designs spanning consumer products, automotive assemblies, 
industrial concepts, and mechanism design. Each folder contains the CAD files along with 
design intent and key decisions.

## Designs

| Design | Domain | Highlights |
|---|---|---|
| [Dynatrap](./dynatrap/) | Industrial / Consumer Product | Functional assembly, form-follows-function |
| [Home Decor Shelf](./home-decor-shelf/) | Aesthetic / Product Design | Geometry, proportions, visual design in CAD |
| [Ice tray](./ice-tray/) | Consumer Product Design | Geometry, form, aesthetic-driven CAD |
| [V8 Engine](./v8-engine/) | Automotive / Mechanical Assembly | Multi-component assembly, motion study |


## Tools
- **Software:** SolidWorks (Parts, Assemblies, Motion Study)
- **Formats:** `.SLDPRT`, `.SLDASM`, `.STEP`

## About
These designs were made to explore different areas of mechanical engineering — from 
aesthetic product design to mechanism synthesis. Each folder has its own README with 
context on the design intent and decisions made.
