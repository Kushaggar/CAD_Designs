# Dynatrap

## What is it?
Dynatrap is an insect trap that uses UV light and CO₂ to attract and capture insects 
without chemicals. This is a SolidWorks model of the device.

## Design Focus
- Functional enclosure design
- Assembly of housing, fan, and grid components
- Form-follows-function product geometry
