# V8 Engine Assembly

## What is it?
A multi-component SolidWorks assembly of a V8 engine, modelling the core mechanical 
architecture of an 8-cylinder internal combustion engine.

## Design Focus
- Multi-part assembly structure (crankshaft, pistons, connecting rods, block)
- Mate constraints and motion relationships
- Understanding of IC engine geometry and kinematics
