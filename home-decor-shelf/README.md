# Aesthetic Home Decor Shelf

## What is it?
A decorative wall shelf designed with focus on geometry, proportions, and visual balance — 
exploring how CAD can be used for aesthetic product design, not just functional engineering.

## Design Focus
- Visual proportions and surface geometry
- Practical mounting and load considerations
- Demonstrates CAD as a design tool beyond engineering parts
